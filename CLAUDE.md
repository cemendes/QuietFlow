## What this project is

QuietFlow is a calm, local-first Markdown task & notes manager, purpose-built for neurodivergent-friendly focus (ADHD-friendly patterns: "One-Thing" Zen Theater, Magic Slicer task breakdown, Breadcrumb Trail re-entry, dopamine micro-rewards) and for anyone who wants a distraction-light way to stay organized. Built by Rogério (UFRJ, Brazil) and his brother Eduardo (Google Cloud, Austin) as a shared side project.

Working name in older code/docs: **FocusFlow** — the current cross-platform rewrite is branded **QuietFlow**. Don't be surprised to see both names in the tree.

## Tech stack (the active app — repo root)

- **Desktop shell:** Tauri 2.0 (Rust) — atomic file writes (`.tmp` + rename), `notify` crate for directory watching, global shortcut registration
- **Frontend:** React 18/19 + TypeScript + Vite + Tailwind CSS, Lucide icons, `clsx` / `tailwind-merge`
- **State:** Zustand store at `src/store/vaultStore.ts`
- **Data model:** the vault is plain `.md` files with YAML frontmatter; tasks are GitHub-flavored checklist items (`- [ ]` / `- [/]` / `- [x]`) with `@due(YYYY-MM-DD)`, `@priority(low|medium|high)`, `#tags`, parsed non-destructively (`src/core/markdown/parser.ts` + `serializer.ts` — never mangle unrelated markdown/frontmatter when editing a task)
- **Theme:** "Warm Sand & Forest Emerald" — canvas `#FAF9F6`, forest emerald `#065F46`, terracotta priority `#C2410C`
- **Testing:** Vitest + React Testing Library (unit/component), Playwright (`tests/e2e/playwright-user-journey.spec.ts`), `cargo check --manifest-path src-tauri/Cargo.toml` for the Rust side
- **Version:** see `package.json` (`0.1.0-alpha.2` as of Aug 2026)
